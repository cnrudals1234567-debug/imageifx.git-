# 네이버 GFA 이미지 배너(1250×560) 제작 기준

조사일: 2026-10-17. imageifx의 `presets/presets.json` → `gfa_1250x560`과 `imageifx/validate.py`가 이 문서를 기준으로 동작한다.

> **주의**: 네이버 공식 가이드 원문(ads.naver.com/adguide/1474)은 조사 도구로 열 수 없었다.
> 아래 값은 모두 2차 자료이며, 신뢰도 등급을 규칙마다 표시했다. 반려가 계속되면 광고관리자 소재 등록 화면의 안내 문구가 최종 기준이다.

## 신뢰도 등급
- **A** 서로 다른 출처 2곳 이상이 일치
- **B** 출처 1곳. 단, 그 출처가 "공식 제작 가이드 원문을 옮긴 것"이라고 밝히고 구체적 수치를 제시
- **C** 실무 경험칙 또는 단일 출처의 보조 항목

## 규칙표

| 규칙 | 값 | 등급 | 도구에서의 처리 |
|---|---|---|---|
| 이미지 크기 | 1250×560 px 고정 | A | FAIL |
| 파일 형식 | JPG, PNG (투명 배경 불가) | A (2024 자료는 JPEG 포함) | 출력은 항상 불투명 RGB |
| 용량 | 50KB 이상 250KB 이하 | A | FAIL. 1KB=1000B 기준으로 판정 |
| 안전영역 | 상 50, 하 35, 좌우 각 240 px → 안전영역 770×475 | B | 글자·로고·CTA는 FAIL, 피사체는 경고 |
| 글자·로고 위치 | 안전영역 안쪽에 모은다 | B | FAIL |
| 배경 | 1250×560 전체를 채운다 | B | - |
| 가장자리 | 흰색/검정으로 채워 비율 맞추기 금지 (잘린 소재로 판단) | B | FAIL |
| 흰색 면적 | 전체의 50% 초과 금지 | B | FAIL (밝기 245 이상을 흰색으로 계산) |
| 배경색 | #F2F2F2 계열 금지 (광고 영역 식별 불가) | B | FAIL |
| 좌우 그라데이션 | 폐지됨 | B | 사용 안 함 |
| 글자 높이 | 22~52 px | C | 경고 |
| 글자 줄 수 | 로고 제외 최대 4줄 | C | 경고 (밑줄이 줄로 잡힐 수 있음) |
| 글자 색 | 최대 3가지 | C | 경고 (근사 계산) |
| 텍스트 면적 비율 | 20% 이내 권장. 로고·CTA 문구·가격 포함 | C (실무 기준, 공식 규정 아님) | 경고 |
| 효능·보장 문구 | "즉시 효과", "100% 개선" 등은 반려 다수, 근거자료 필요 | C | 도구 검사 없음, 사람이 확인 |

## 출처 간 불일치 (확정하지 못한 것)
- **좌우 여백**: 한 자료 안에서 240px과 225px이 엇갈린다. 더 넓은 240px을 채택했다. 안전영역 770px은 1250−480으로 일치하므로 240이 맞을 가능성이 높다.
- **용량**: 2024 자료는 "250KB, 230KB 이하"라고만 쓰고 어느 사이즈에 적용되는지 밝히지 않았다. 250KB 상한(2025·2026 자료 일치)을 채택했고, 안전하게 230KB 이하로 맞추면 두 기준을 모두 만족한다.
- **노출 지면**: 모바일 메인/서비스 통합(다수) vs 스마트채널(1건). 1250×560은 모바일 DA 이미지 배너로 본다.
- **글자 높이 22~52px**: 1250×560에서 52px가 헤드라인에도 적용되는 값인지 근거가 부족하다. 경고로만 표시한다.

## 기기별 잘림에 대한 해석
좌우 240px 구역은 기기 해상도에 따라 배너가 좌우로 늘고 줄면서 잘릴 수 있는 영역이다. 그래서
- 글자·로고·CTA는 반드시 안전영역 안에 둔다.
- 인물·마스코트 등 **장식적 주요 디자인은 안전영역 밖으로 나가도 되지만**, 얼굴이나 핵심 부분이 밖에 걸리지 않게 눈으로 확인한다.

## 광고관리자에서 직접 확인할 항목
1. 안전영역 수치(상 50 / 하 35 / 좌우 240)가 등록 화면 안내와 같은지
2. 흰색 50%, #F2F2F2 금지가 현재도 유효한지
3. JPG 업로드 가능 여부, 용량 한도(250KB / 230KB)
4. 글자 높이 22~52px 규정이 실제로 있는지
