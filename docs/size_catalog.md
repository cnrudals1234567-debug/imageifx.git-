# 매체별 사이즈 카탈로그

조사일: 2026-10-17. `presets/presets.json`의 `group`·`grade`·`verified`·`note`가 이 문서와 같은 내용을 담는다(웹 화면의 배지도 여기서 온다).
GFA 1250×560의 상세 규칙과 근거는 `docs/gfa_guide.md`를 본다.

> **주의**: 공식 원문을 직접 열어 확인한 것은 구글 반응형 디스플레이(검색 결과로 확인한 공식 페이지 내용)뿐이다.
> 네이버·메타는 공식 원문을 열지 못했고 2차 자료(광고대행사·마케팅 블로그)에 의존한다. 등급 정의는 `docs/gfa_guide.md`와 같다
> (A 서로 다른 출처 2곳 이상 일치, B 단일 출처이나 구체적 수치, C 경험칙·단일 보조 출처). **"확정"이라고 부르지 않는다.**

숨김(웹 목록에 안 보이고 CLI에서는 계속 동작): `gfa_1200x560`(근거 없는 임시 값), `google_1080x1920`(공식 규격이 아님. 공식 세로는 900×1600).
구형 GFA 1250×370(서브 영역)은 만들지 않았다.

## 이번에 하지 않은 것
- 구글 표준 배너(300×250, 728×90, 300×600, 320×100 등): 극단 비율이라 새 배치 모드가 필요하다. 출처에 따라 150KB 한도가 언급되지만 구글 공식으로는 확인하지 못했다.
- 메타 캐러셀·컬렉션·마켓플레이스 등 별도 규격.

## 배치 방식
- 규정 계열은 `mode`(gfa/free), 배치 방식은 `layout`(없으면 `mode`)이다. 정사각·1.9:1 GFA 피드는 규정은 gfa 계열이지만 배치는 `free`를 쓴다.
- `free` 배치: 가로형(W/H ≥ 1.3)은 `auto_gfa`, 정사각·4:5는 `auto_free`(원본의 요소 배열을 유지), 세로 9:16(H/W ≥ 1.6)은 `auto_stack`. `safe_zone`이 있는 프리셋은 방향별 여백을 따른다.
- **알려진 한계**: 소재에 따라 FAIL이 날 수 있다. 정사각·4:5는 원본에서 인물이 글자 가까이 있으면 실루엣 간격 FAIL이 나며, 웹의 "자동 보정"이 글자 블록을 옮겨 푸는 경우가 많다. 세로 9:16은 받침대 위 소품(`stay_y`)이 자리를 못 찾아 `LOST`가 날 수 있고, 웹의 "장식 빼기"로 정리한다. 이런 결과도 이미지를 직접 열어 확인한다.

## 광고관리자·Ads Manager에서 직접 확인할 항목
1. 네이티브 피드(1200×1200, 1200×680)의 용량 한도(800KB)와 안전영역이 있는지
2. 메타 스토리·릴스 안전영역 수치(Ads Manager 미리보기)
3. 구글 4:5(960×1200) 등록 가능 여부
